# Папка входных данных

Сюда кладутся папки проектов для сборки видео.

Структура одного проекта:
```
input/
  Ролик/
    slide_1.jpg, slide_2.jpg ...      — изображения слайдов
    audio_1.wav, audio_2.wav ...      — аудиодорожки
    subtitles.txt                     — субтитры с разметкой «Слайд N»
```

Связывание файлов — по номеру в имени: `slide_1` ↔ `audio_1` ↔ блок «Слайд 1».

Содержимое этой папки игнорируется git (см. корневой `.gitignore`), но сама папка сохранена через `.gitkeep`, чтобы она была видна на GitHub.
