# video_maker_no_ai

**Сборка видео из слайдов (jpg) + аудиодорожек (wav) + субтитров (txt) — полностью оффлайн, без облачных API.**

Предназначен для работы в закрытом банковском контуре, где нет доступа к внешним сервисам. FFmpeg поставляется как Python-колесо (`imageio-ffmpeg`) — отдельная установка бинарника не требуется.

## Как это работает

Скрипт берёт папку проекта с изображениями слайдов, WAV-аудио и файлом субтитров, и собирает MP4, где:

- каждый слайд показывается ровно столько, сколько длится его аудиодорожка (опор на звук: пока идёт звук — слайд на экране);
- поверх слайда идут субтитры в одну строку, сменяющиеся по тайм-кодам;
- между слайдами — настраиваемая анимация перехода.

Пайплайн: `scan → match → validate → render`.

1. **Сканирование** — поиск jpg/wav/txt в папке проекта, извлечение номера слайда из имени файла.
2. **Сопоставление** — связывание `slide_N` + `audio_N` + блок «Слайд N» по номеру; длительность слайда = длительность аудио.
3. **Проверка** — печать сводной таблицы соответствий (слайд → аудио → длительность → кол-во фраз) и предупреждений о несостыковках для визуального контроля.
4. **Рендеринг** — сборка клипов, наложение субтитров, анимации переходов, экспорт в mp4.

## Структура входных данных

```
input/
  Ролик/
    slide_1.jpg
    slide_2.jpg
    audio_1.wav
    audio_2.wav
    subtitles.txt
```

**Связывание** — по номеру в имени файла: `slide_1` ↔ `audio_1` ↔ блок «Слайд 1». Расширения изображений регистронезависимы (`.jpg`, `.JPG`).

### Формат `subtitles.txt`

Под маркером «Слайд N» идут фразы субтитров. Поддерживаются два варианта:

**1. С явными тайм-кодами** — `[mm:ss]` это момент появления фразы от начала слайда. Фраза показывается до тайм-кода следующей; последняя — до конца аудио.

```
Слайд 1
[00:00] Первое предложение субтитра.
[00:03] Второе предложение.
```

**2. Без тайм-кодов** — каждая непустая строка отдельная фраза. Время показа распределяется равномерно по длительности аудио слайда.

```
Слайд 1
День добрый, Коллеги.
Первое предложение субтитра.
Второе предложение.
```

Смешивать оба формата внутри одного блока можно: фразы без тайм-кода равномерно заполняют промежутки между явными.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

### Через консоль

```bash
python main.py --project "input/Ролик" --output "output/Ролик.mp4"
python main.py --transition fade --transition-duration 0.7
python main.py --font-size 56 --subtitle-position bottom
```

Все параметры (разрешение, fps, шрифт/цвет/позиция/размер субтитров, тип и длительность перехода) задаются в [`config/default_config.py`](config/default_config.py) и переопределяются аргументами CLI.

### Через ноутбук

Откройте [`notebook.ipynb`](notebook.ipynb): параметры — в первой ячейке, запуск пайплайна — во второй.

## Анимации переходов

`none` (резкий срез), `fade` (затемнение), `crossfade` (плавный переход), `slide_left` (сдвиг). Выбор — через параметр `transition.type`. Новые переходы добавляются в [`src/rendering/transitions.py`](src/rendering/transitions.py) по паттерну стратегии (Open/Closed).

## Архитектура

```
main.py / notebook.ipynb    точки входа (CLI и ноутбук)
config/default_config.py    все параметры
src/pipeline.py             scan → match → validate → render
src/scanner.py              поиск jpg/wav/txt по номеру в имени
src/subtitle_parser.py      разбор txt (оба формата)
src/audio_probe.py          длительность wav (встроенный модуль wave)
src/matcher.py              связывание + распределение времени
src/validator.py            сводная таблица + проверки
src/rendering/              клипы, субтитры (Pillow), переходы, экспорт
```

Принципы: SOLID, DRY, KISS. Файлы ≤ 200 строк, единая ответственность.

## Перенос в закрытый контур

### Вариант A — готовый zip

```bash
python make_release.py
```

Создаст `dist/video_maker_no_ai_v1.0.zip` со строго необходимым набором файлов для локальной установки (исходники + requirements, без тестов и кэша). Передаётся по почте.

### Вариант B — wheels для оффлайн-установки

1. На машине с интернетом: `pip download -r requirements.txt -d wheels`.
2. В контуре: `pip install --no-index --find-links wheels -r requirements.txt`.
3. Запускайте `python main.py` или `notebook.ipynb`.

FFmpeg уже внутри (через `imageio-ffmpeg`), внешних бинарных зависимостей нет.
